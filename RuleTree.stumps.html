class Stump(transformer=None, splitter=None)[source]#

Bases: RuleTreeBaseStump

Stump made of a transformer and a splitter: the transformer turns the data of one type into a feature matrix, the splitter finds the best split of that matrix.

Any transformer can be combined with any splitter. The data types supported by the stump are the ones of the transformer, and its task (classification or regression) is the one of the splitter. The stumps of the library are subclasses that build the two components from their own parameters (_make_transformer and _make_splitter); see Extending the library to write new ones.

Parameters:

  • transformer (RuleTreeBaseTransformer, default=None) – Transformer of the data into a feature matrix; it is cloned at each fit.

  • splitter (RuleTreeBaseSplitter, default=None) – Splitter of the feature matrix; it is cloned at each fit.

Variables:

  • transformer (RuleTreeBaseTransformer) – The fitted transformer.

  • splitter (RuleTreeBaseSplitter) – The fitted splitter (feature, threshold, gain and impurity of the split).

  • data_type (str) – Data type the stump was fitted on.

  • feature_original (int or str) – Feature of the split, as identified by the transformer: a column of the data, a pivot, …

  • threshold_original (float or object) – Threshold of a numerical split, or value of a categorical split.

Examples

>>> from sklearn.datasets import load_diabetes
>>> from RuleTree import RuleTreeRegressor
>>> from RuleTree.stumps.Stump import Stump
>>> from RuleTree.stumps.splitters import FairSplitter, RegressionSplitter
>>> from RuleTree.stumps.transformers import MatrixTransformer, PivotTransformer
>>> from RuleTree.utils.define import MODEL_TYPE_REG
>>> X, y = load_diabetes(return_X_y=True)
>>> stump = Stump(PivotTransformer(MODEL_TYPE_REG), RegressionSplitter())
>>> stump.task, stump.supported_data_types
('reg', ('tabular',))
>>> model = RuleTreeRegressor(max_depth=2, base_stumps=stump).fit(X[:100], y[:100])

set_fit_request(*, check_input: bool | None | str = '$UNCHANGED$', context: bool | None | str = '$UNCHANGED$', data: bool | None | str = '$UNCHANGED$', data_type: bool | None | str = '$UNCHANGED$', idx: bool | None | str = '$UNCHANGED$', sample_weight: bool | None | str = '$UNCHANGED$') → Stump#

Configure whether metadata should be requested to be passed to the fit method.

Note that this method is only relevant when this estimator is used as a sub-estimator within a meta-estimator and metadata routing is enabled with enable_metadata_routing=True (see sklearn.set_config()). Please check the User Guide on how the routing mechanism works.

The options for each parameter are:

  • True: metadata is requested, and passed to fit if provided. The request is ignored if metadata is not provided.

  • False: metadata is not requested and the meta-estimator will not pass it to fit.

  • None: metadata is not requested, and the meta-estimator will raise an error if the user provides it.

  • str: metadata should be passed to the meta-estimator with this given alias instead of the original name.

The default (sklearn.utils.metadata_routing.UNCHANGED) retains the existing request. This allows you to change the request for some parameters and not others.

Added in version 1.3.

Parameters:
