RuleTreeClassifier#

class RuleTreeClassifier(max_leaf_nodes=inf, min_samples_split=2, max_depth=inf, prune_useless_leaves=False, base_stumps: ClassifierMixin | list = None, stump_selection: str = 'random', random_state=None)[source]#

Bases: ClassifierMixin, RuleTree

RuleTree for classification.

The tree grows breadth-first; a node is not split if it is pure. Each node predicts the majority class of its instances and stores the class probabilities and log-odds.

Parameters:

  • max_leaf_nodes (int, default=inf) – Maximum number of leaves.

  • min_samples_split (int, default=2) – Minimum number of instances to split a node.

  • max_depth (int, default=inf) – Maximum depth of the tree (the root has depth 0).

  • prune_useless_leaves (bool, default=False) – Whether to merge, after fit, the sibling leaves with the same prediction.

  • base_stumps (RuleTreeBaseStump or list, default=None) – Stumps used to split the nodes (see RuleTree.tree.RuleTree.RuleTree); they must be classification stumps. If None, DecisionTreeStumpClassifier().

  • stump_selection ({'random', 'best'}, default='random') – How the stump of each node is chosen among base_stumps.

  • random_state (int, RandomState instance or None, default=None) – Seed of the random choice of the stumps, also given to the stumps without a random_state.

Variables:

  • classes (numpy.ndarray) – Classes of the target.

  • n_classes (int) – Number of classes.

  • root (RuleTreeNode) – Root of the fitted tree.

  • candidate_splits (list of tuple) – (probability, stump, data_type): the stumps usable on the training data, with the data type they are used on.

  • cache (dict) – Values cached by the stumps during fit (see get_cache()).

See also

Examples

>>> from sklearn.datasets import load_iris
>>> from RuleTree import RuleTreeClassifier
>>> X, y = load_iris(return_X_y=True)
>>> model = RuleTreeClassifier(max_depth=2, random_state=0).fit(X, y)
>>> model.predict(X[:3])
array([0, 0, 0])

local_interpretation(X, joint_contribution=False)[source]#

Contribution of each feature to the predicted class probabilities, as in treeinterpreter: the probabilities of an instance are the ones of the root (bias) plus the contributions of the features of the splits along its path.

Parameters:

  • X (numpy.ndarray of shape (n_samples, n_features)) – Tabular data.

  • joint_contribution (bool, default=False) – If True, the contributions are given to the sets of features along the path.

Returns:

  • prediction (numpy.ndarray of shape (n_samples, n_classes)) – Class probabilities of the leaf of each instance.

  • bias (numpy.ndarray of shape (n_samples, n_classes)) – Class probabilities of the root.

  • contributions (numpy.ndarray of shape (n_samples, n_features, n_classes) or list of dict) – Contribution of each feature (or set of features, with joint_contribution).
