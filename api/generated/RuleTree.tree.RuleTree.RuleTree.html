RuleTree#

class RuleTree(max_leaf_nodes, min_samples_split, max_depth, prune_useless_leaves, base_stumps, stump_selection, random_state, exceptions='raise')[source]#

Bases: RuleTreeBase, ABC

Base class of the RuleTree models.

A RuleTree is a binary decision tree built best-first: the nodes are split one at a time, in the order given by queue_push, until a stopping criterion is met. Each split is a stump (see RuleTree.base.RuleTreeBaseStump.RuleTreeBaseStump) chosen among base_stumps, so the same tree can mix different kinds of splits (thresholds on features, distances from pivots, shapelets, …) and different data types (tabular data, time series, images).

The subclasses define the task: RuleTreeClassifier, RuleTreeRegressor, RuleTreeCluster and its variants.

Parameters:

  • max_leaf_nodes (int, default=None) – Maximum number of leaves. If None, unlimited.

  • min_samples_split (int) – Minimum number of instances to split a node.

  • max_depth (int) – Maximum depth of the tree (the root has depth 0).

  • prune_useless_leaves (bool) – Whether to merge, after fit, the sibling leaves with the same prediction.

  • base_stumps (RuleTreeBaseStump or list) –

    Stumps used to split the nodes. One of:

    • a stump;

    • a list of stumps, chosen with equal probability;

    • a list of tuples (probability, stump) or (probability, stump, data_types), where the probabilities sum to 1 and data_types (a data type or a list of data types, see RuleTree.utils.define.DATA_INPUT_TYPES) restricts the data the stump is used on. By default, a stump is used on every data type it supports. The probability of a stump is split equally among its data types.

  • stump_selection ({'random', 'best'}) – How the stump of each node is chosen: at random according to the probabilities, or the one with the highest gain among all the stumps and data types.

  • random_state (int, RandomState instance or None) – Seed of the random choice of the stumps, also given to the stumps whose random_state is None (so that they do not break ties at random).

  • exceptions ({'raise', 'ignore'}, default='raise') – What to do when a stump raises an error: raise it, or make the node a leaf and warn.

Variables:

  • root (RuleTreeNode) – Root of the fitted tree.

  • candidate_splits (list of tuple) – Pairs (stump, data type) usable on the training data, with their probability: (probability, stump, data_type).

  • cache (dict) – Values cached by the stumps during fit (see get_cache()).

See also

RuleTreeClassifier, RuleTreeRegressor, RuleTreeCluster

fit(X: ndarray | None = None, y: ndarray | None = None, X_ts: ndarray | None = None, X_img: ndarray | None = None, X_txt: ndarray | None = None, sample_weight=None)[source]#

Fit the tree on the provided data, starting from an empty tree.

At least one of X, X_ts, X_img and X_txt must be given; all the inputs refer to the same instances. Each argument is a data type (see RuleTree.utils.define.DATA_INPUT_TYPES): the stumps are used on the data types they support.

Parameters:

  • X (numpy.ndarray of shape (n_samples, n_features), default=None) – Tabular data.

  • y (numpy.ndarray of shape (n_samples,), default=None) – Target (None for clustering).

  • X_ts (numpy.ndarray of shape (n_samples, n_signals, length), default=None) – Time series.

  • X_img (numpy.ndarray of shape (n_samples, ...), default=None) – Images.

  • X_txt (array-like of shape (n_samples,), default=None) – Texts.

  • sample_weight (numpy.ndarray of shape (n_samples,), default=None) – Sample weights, passed to the stumps.

Returns:

self – The fitted tree.

Return type:

RuleTree

Raises:

ValueError – If no input is given, the inputs have different numbers of instances, or no stump supports the provided data.

partial_fit(X: ndarray | None = None, y: ndarray | None = None, X_ts: ndarray | None = None, X_img: ndarray | None = None, X_txt: ndarray | None = None, sample_weight=None)[source]#

Continue growing the fitted tree: the current leaves are split further using the provided data, within the limits of max_depth and max_leaf_nodes (e.g. after increasing them with set_params). The existing splits are not changed. If the tree is not fitted, this is fit().

The cache of the stumps (see get_cache()) is kept: call clear_cache() first if the data differ from those used to fill it.

Parameters:

  • y (numpy.ndarray of shape (n_samples,), default=None) – Target (None for clustering).

  • X_ts (numpy.ndarray of shape (n_samples, n_signals, length), default=None) – Time series.

  • X_img (numpy.ndarray of shape (n_samples, ...), default=None) – Images.

  • X_txt (array-like of shape (n_samples,), default=None) – Texts.

  • sample_weight (numpy.ndarray of shape (n_samples,), default=None) – Sample weights, passed to the stumps.

Returns:

self – The fitted tree.

plot_tree(ax=None, *, columns_names=None, class_names=None, scaler=None, float_precision=3, max_depth=None, node_ids=True, samples=True, filled=True, fontsize=None, colors=None, wrap=None)[source]#

Draw the tree with matplotlib, as sklearn.tree.plot_tree (requires matplotlib).

Each internal node shows its id, its rule (for the shapelet and proximity stumps, also a plot of the shapelets) and its number of training instances; each leaf its prediction. The left child of a node (arrow “true”) gets the instances for which the rule is true. Unlike export_graphviz, it needs neither the Graphviz programs nor files: the drawing is a matplotlib figure, shown in notebooks and saved with savefig.

Parameters:

  • ax (matplotlib.axes.Axes, default=None) – Axes to draw on. If None, a new figure, sized on the number of leaves and the depth.

  • columns_names (list of str, default=None) – Names of the tabular features.

  • class_names (list of str, default=None) – Names of the classes, in the order of classes_ (classification trees).

  • scaler (TransformerMixin, default=None) – Scaler used to preprocess the data: the thresholds are shown in the original scale.

  • float_precision (int, default=3) – Number of decimals of the thresholds and of the predicted values.

  • max_depth (int, default=None) – Maximum depth drawn: the subtrees below are shown as (...). If None, the whole tree.

  • node_ids (bool, default=True) – Whether to show the id of each node.

  • samples (bool, default=True) – Whether to show the number of training instances of each node.

  • filled (bool, default=True) – Whether to color the leaves by class, cluster or predicted value.

  • fontsize (float, default=None) – Size of the text. If None, the largest size with which the boxes do not overlap.

  • colors (dict, default=None) – Colors replacing the ones of RuleTree.utils.plotting.DEFAULT_COLORS (e.g. for a dark background): text, split, split_edge, leaf, leaf_edge, edge, classes (a list) and values (a colormap).

  • wrap (int, default=None) – Maximum number of characters per line: longer rules are split before their comparison operator, then between words, so that the boxes of trees with long feature names are narrower. If None, one line per rule.

Returns:

ax – The axes of the drawing. The box of each node is a text of ax.texts whose gid is the id of the node.

Return type:

matplotlib.axes.Axes

Examples

>>> import matplotlib
>>> matplotlib.use("Agg")
>>> from sklearn.datasets import load_iris
>>> from RuleTree import RuleTreeClassifier
>>> iris = load_iris()
>>> model = RuleTreeClassifier(max_depth=2, random_state=0).fit(iris.data, iris.target)
>>> ax = model.plot_tree(columns_names=iris.feature_names, class_names=list(iris.target_names))
>>> [text.get_text().split("\n")[1] for text in ax.texts if text.get_gid() in ("R", "Rl")]
['petal width (cm) <= 0.8', 'class = setosa']
