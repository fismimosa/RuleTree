RuleTreeBaseStump#

class RuleTreeBaseStump[source]#

Bases: BaseEstimator, ABC

Abstract base class of the stumps, the splits of the nodes of a RuleTree.

A stump divides the instances of a node into two children: apply returns 1 for the instances that go to the left child and 2 for the ones that go to the right child.

Notes

Stumps receive the whole data set as a dictionary data = {data_type: array} (see RuleTree.utils.define.DATA_INPUT_TYPES) together with idx, the indices of the instances reaching the node. A fitted stump works on a single data type, chosen by the tree among supported_data_types and stored in data_type_. For convenience, data can also be a single array, interpreted as data of the stump’s data type.

The tree passes its cache to every stump, transformer and splitter (cache, a dictionary namespace -> dictionary of values that lives until the next fit or clear_cache()), where they can store anything that can be shared among splits, e.g. embeddings computed on the whole data set. The code of each component decides whether and how to use it: the ones of the library keep their values under their own namespace, self._get_cache(cache) (cache_namespace(): the class and the hyperparameters). Everything needed by apply must be stored in the stump itself.

The tree also passes node_id, the identifier of the node being split ("R", "Rl", …): with context.get_node_by_id(node_id) the stump reaches the node, and from it its ancestors and their stumps. The node is a leaf while its stump is fitted; its ancestors are already split. context, node_id and cache are required in fit and update_statistics (None outside a tree), optional in apply.

Subclasses that work on a 2D matrix can implement _transform (data of the stump’s data type -> matrix) and _apply_matrix (matrix -> 1/2 labels) and reuse apply() and update_statistics(). The stumps of the library are made of a transformer and a splitter (see RuleTree.stumps.Stump.Stump), which is the simplest way to write a new stump.

Variables:

  • supported_data_types (tuple of str) – Data types the stump can be fitted on.

  • task (str) – Kind of target, MODEL_TYPE_CLF (classification) or MODEL_TYPE_REG (regression).

  • data_type (str) – Data type the stump has been fitted on.

  • node_id (str or None) – Identifier of the node of the stump in its tree (set by fit and by RuleTreeNode.set_stump), None for a stump outside a tree.

See also

RuleTree.stumps.Stump.Stump

a stump made of a transformer and a splitter, the simplest way to write a new stump (see Extending the library).

Fit the stump on the instances idx of data.

Parameters:

  • data (dict or numpy.ndarray) – Whole data set, as {data_type: array}.

  • y (numpy.ndarray) – Target of the whole data set.

  • idx (numpy.ndarray, default=None) – Indices of the instances reaching the node. If None, all the instances.

  • data_type (str, default=None) – Data type to use. If None, the first supported data type available in data.

  • sample_weight (numpy.ndarray, default=None) – Sample weights of the whole data set.

  • check_input (bool, default=True) – Whether to check the input data.

  • context (RuleTree or None) – Tree being built, None outside a tree: it holds the cache shared among the splits, and it is passed to the transformer and the splitter.

  • node_id (str or None) – Identifier of the node being split, stored in node_id_. None outside a tree.

  • cache (dict or None) – Cache of the tree (namespace -> dictionary of values), None outside a tree: the component decides whether and how to use it (the ones of the library use self._get_cache(cache)).

self – The fitted stump.

cache_namespace() → str[source]#

Name of the cache of the stump in the tree (see RuleTree.get_cache): the class name and a hash of the hyperparameters, also of the components (e.g. the transformer of a Stump). Stumps of the same class with different hyperparameters do not share cached values.

The tree gives its random_state to the stumps without one, so the namespace of a stump used by a tree is the one of its copy in candidate_splits_.

Returns:

namespace – E.g. "PivotTreeStumpClassifier-1a2b3c4d".

Return type:

str

Examples

>>> from RuleTree.stumps.classification import DecisionTreeStumpClassifier
>>> a, b = DecisionTreeStumpClassifier(), DecisionTreeStumpClassifier(criterion="entropy")
>>> a.cache_namespace().startswith("DecisionTreeStumpClassifier-")
True
>>> a.cache_namespace() == DecisionTreeStumpClassifier().cache_namespace() != b.cache_namespace()
True
