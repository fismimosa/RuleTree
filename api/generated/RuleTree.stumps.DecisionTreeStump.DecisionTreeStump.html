DecisionTreeStump#

class DecisionTreeStump(transformer=None, splitter=None)[source]#

Bases: Stump

Base class of the decision tree stumps (DecisionTreeStumpClassifier and DecisionTreeStumpRegressor): a MatrixTransformer and the splitter _splitter_class (ClassificationSplitter or RegressionSplitter) with the parameters of the stump.

A subclass defines its parameters (__init__) and _splitter_class.
