RuleTree.tree.RuleTree module#

Base class of the RuleTree models: a decision tree built node by node, where each node is split by a stump chosen among the base stumps.

class RuleTree(max_leaf_nodes, min_samples_split, max_depth, prune_useless_leaves, base_stumps, stump_selection, random_state, exceptions='raise')[source]#

Bases: RuleTreeBase, ABC

Base class of the RuleTree models.

A RuleTree is a binary decision tree built best-first: the nodes are split one at a time, in the order given by queue_push, until a stopping criterion is met. Each split is a stump (see RuleTree.base.RuleTreeBaseStump.RuleTreeBaseStump) chosen among base_stumps, so the same tree can mix different kinds of splits (thresholds on features, distances from pivots, shapelets, …) and different data types (tabular data, time series, images).

The subclasses define the task: RuleTreeClassifier, RuleTreeRegressor, RuleTreeCluster and its variants.

Parameters:

  • max_leaf_nodes (int, default=None) – Maximum number of leaves. If None, unlimited.

  • min_samples_split (int) – Minimum number of instances to split a node.

  • max_depth (int) – Maximum depth of the tree (the root has depth 0).

  • prune_useless_leaves (bool) – Whether to merge, after fit, the sibling leaves with the same prediction.

  • base_stumps (RuleTreeBaseStump or list) –

    Stumps used to split the nodes. One of:

    • a stump;

    • a list of stumps, chosen with equal probability;

    • a list of tuples (probability, stump) or (probability, stump, data_types), where the probabilities sum to 1 and data_types (a data type or a list of data types, see RuleTree.utils.define.DATA_INPUT_TYPES) restricts the data the stump is used on. By default, a stump is used on every data type it supports. The probability of a stump is split equally among its data types.

  • stump_selection ({'random', 'best'}) – How the stump of each node is chosen: at random according to the probabilities, or the one with the highest gain among all the stumps and data types.

  • random_state (int, RandomState instance or None) – Seed of the random choice of the stumps, also given to the stumps whose random_state is None (so that they do not break ties at random).

  • exceptions ({'raise', 'ignore'}, default='raise') – What to do when a stump raises an error: raise it, or make the node a leaf and warn.

Variables:

  • root (RuleTreeNode) – Root of the fitted tree.

  • candidate_splits (list of tuple) – Pairs (stump, data type) usable on the training data, with their probability: (probability, stump, data_type).

  • cache (dict) – Values cached by the stumps during fit (see get_cache()).

See also

RuleTree for classification.

The tree grows breadth-first; a node is not split if it is pure. Each node predicts the majority class of its instances and stores the class probabilities and log-odds.

  • stump_selection ({'random', 'best'}, default='random') – How the stump of each node is chosen among base_stumps.

class RuleTreeCluster(n_components: int = 2, clus_impurity: str = 'r2', bic_eps: float = 0.0, max_leaf_nodes=inf, min_samples_split=2, max_depth=inf, prune_useless_leaves=False, base_stumps: RegressorMixin | list = None, random_state=None)[source]#

Bases: ClusterMixin, RuleTree

RuleTree for clustering: each leaf is a cluster described by the rules of its path.

To split a node, the instances are projected on their principal components (PCA, MCA or FAMD, for numerical, categorical or mixed data); for each component, a regression stump is fitted to predict it, and the best split is kept according to clus_impurity. A node is split only if the split decreases its BIC (see bic_eps). The tree grows from the largest node. Only tabular data are supported.

After fit, the nodes predict integer labels assigned in breadth-first order (‘R’ -> 0, ‘Rl’ -> 1, ‘Rr’ -> 2, …); predict returns the label of the leaf of each instance.

Parameters:

  • n_components (int, default=2) – Number of principal components predicted by the stumps of each node.

  • clus_impurity ({'r2', 'bic'}, default='r2') – Criterion to choose the split among the ones on the different components: the variance of the component explained by the split (‘r2’) or the Bayesian Information Criterion of the two clusters (‘bic’).

  • bic_eps (float, default=0.0) – A split is kept only if it decreases the BIC of the node by more than bic_eps times its value.

  • max_leaf_nodes (int, default=inf) – Maximum number of leaves.

  • min_samples_split (int, default=2) – Minimum number of instances to split a node.

  • max_depth (int, default=inf) – Maximum depth of the tree (the root has depth 0).

  • prune_useless_leaves (bool, default=False) – Whether to merge, after fit, the sibling leaves with the same prediction.

  • base_stumps (RuleTreeBaseStump or list, default=None) – Regression stumps used to split the nodes, fitted to predict a principal component. If None, DecisionTreeStumpRegressor().

  • random_state (int, RandomState instance or None, default=None) – Seed of the principal component analysis and of the random choice of the stumps, also given to the stumps without a random_state.

Variables:

  • label_encoder (dict) – Node id -> integer label.

  • root (RuleTreeNode) – Root of the fitted tree.

  • candidate_splits (list of tuple) – (probability, stump, data_type): the stumps usable on the training data, with the data type they are used on.

  • cache (dict) – Values cached by the stumps during fit (see get_cache()).
