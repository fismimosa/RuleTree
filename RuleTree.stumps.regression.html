DecisionTreeStumpRegressor: the split on one feature for regression.

class DecisionTreeStumpRegressor(criterion='squared_error', min_samples_leaf=1, min_weight_fraction_leaf=0.0, max_features=None, random_state=None, min_impurity_decrease=0.0)[source]#

Bases: Stump

Decision tree stump for regression: a threshold on a numerical feature (x <= t) or a value of a categorical feature (x == v), chosen to maximize the decrease of impurity.

It works on tabular data, time series and images; time series and images are flattened into one feature per value. It is a Stump made of a MatrixTransformer and a RegressionSplitter, and the default stump of RuleTreeRegressor.

Parameters:

  • criterion ({'squared_error', 'absolute_error', 'poisson'}, default='squared_error') – Impurity measure.

  • min_samples_leaf (int or float, default=1) – Minimum number of instances in each child (a fraction of the instances of the node if float). Applies to the numerical features.

  • min_weight_fraction_leaf (float, default=0.0) – Minimum fraction of the sample weights of the node in each child. Applies to the numerical features.

  • max_features (int, float, {'sqrt', 'log2'} or None, default=None) – Number of numerical features considered for the split, drawn at random; None for all.

  • random_state (int, RandomState instance or None, default=None) – Seed of the choice of the features (max_features) and of the ties between features with the same gain. With None, a tree gives the stump its own random_state.

  • min_impurity_decrease (float, default=0.0) – A numerical split is kept only if it decreases the weighted impurity by at least this value.

Variables:

  • transformer (MatrixTransformer) – The fitted transformer.

  • splitter (RegressionSplitter) – The fitted splitter (feature, threshold, gain and impurity of the split).

  • data_type (str) – Data type the stump was fitted on.

  • feature_original (int) – Column of the data used by the split.

  • threshold_original (float or object) – Threshold of a numerical split, or value of a categorical split.

See also

DecisionTreeStumpClassifier

the same stump for classification.

sklearn.tree.DecisionTreeRegressor

the tree used to split the numerical features.

Examples

>>> from sklearn.datasets import load_diabetes
>>> from RuleTree.stumps.regression import DecisionTreeStumpRegressor
>>> X, y = load_diabetes(return_X_y=True)
>>> stump = DecisionTreeStumpRegressor(min_samples_leaf=20, random_state=0).fit(X, y)
>>> stump.get_rule()["textual_rule"]
'X_8 <= -0.004'

FairTreeStumpRegressor: the split for regression under a fairness constraint.

class FairTreeStumpRegressor(penalty: str = None, sensible_attribute: int = -1, penalization_weight: float = 0.3, ideal_distribution: dict = None, k_anonymity: int | float = 2, l_diversity: int | float = 2, t_closeness: float = 0.2, strict: bool = True, use_t: bool = True, n_jobs: int = 2, criterion='squared_error')[source]#

Bases: DecisionTreeStumpRegressor

Fair stump for regression: the threshold on a numerical feature with the highest gain, penalized by how unfair the split is with respect to a sensitive attribute.

The sensitive attribute is a column of the data (sensible_attribute), never used by the splits. The fairness criterion (penalty) is statistical parity of the children, a maximum fairness cost with respect to an ideal distribution, or privacy constraints (k-anonymity, l-diversity, t-closeness). It is a Stump made of a MatrixTransformer and a FairSplitter; it supports only tabular data.

Parameters:

  • penalty ({'balance', 'mfc', 'privacy'}, default=None) –

    Fairness criterion, which penalizes the gain of the splits:

    • ’balance’: the children should have the same distribution of the sensitive attribute (statistical parity);

    • ’mfc’: maximum fairness cost with respect to ideal_distribution;

    • ’privacy’: the children must satisfy k-anonymity, l-diversity and t-closeness on the sensitive attribute (with strict=True, the splits that violate them are discarded).

  • sensible_attribute (int, default=-1) – Column of the data with the sensitive attribute. It is never used by the splits.

  • penalization_weight (float, default=0.3) – Weight of the penalty: the gain of a split is sigmoid(gain) * (1 - penalty * weight).

  • ideal_distribution (dict, default=None) – Value of the sensitive attribute -> ideal fraction, required by penalty=’mfc’.

  • k_anonymity (int or float, default=2) – Minimum number of instances in each child (penalty=’privacy’).

  • l_diversity (int or float, default=2) – Minimum number of distinct values of the sensitive attribute in each child (penalty=’privacy’).

  • t_closeness (float, default=0.2) – Maximum distance between the distribution of the sensitive attribute in a child and in the node (penalty=’privacy’).

  • strict (bool, default=True) – Whether the privacy constraints discard the splits that violate them, instead of only penalizing them.

  • use_t (bool, default=True) – Whether t-closeness is part of the privacy constraints.

  • n_jobs (int, default=number of physical CPUs) – Number of processes used to evaluate the features.

  • criterion ({'squared_error', 'absolute_error', 'poisson'} or callable, default='squared_error') – Impurity measure (see RegressionSplitter).

Variables:

  • transformer (MatrixTransformer) – The fitted transformer.

  • splitter (FairSplitter) – The fitted splitter (feature, threshold, gain and impurity of the split).

  • data_type (str) – Data type the stump was fitted on.

  • feature_original (int) – Column of the data used by the split.

  • threshold_original (float) – Threshold of the split.

See also

FairSplitter

the splitter, usable with other transformers (e.g. pivots).

Examples

>>> import numpy as np
>>> from sklearn.datasets import load_diabetes
>>> from RuleTree.stumps.regression import FairTreeStumpRegressor
>>> X, y = load_diabetes(return_X_y=True)
>>> X = np.column_stack([X, X[:, 1] > 0])  # last column: the sensitive attribute
>>> stump = FairTreeStumpRegressor(penalty="balance", sensible_attribute=-1, n_jobs=1).fit(X, y)
>>> stump.get_rule()["textual_rule"]
'X_4 <= -0.03'

Oblique stump for regression of tabular data: a threshold on a linear combination of a few numerical features (0.8 * X_2 - 0.6 * X_3 <= t goes left).

PivotTreeStumpRegressor: the split on the distance from a pivot instance, for regression.

class PivotTreeStumpRegressor(distance_measure='euclidean', k=None, reg_contrast_lambda=0.2, reg_max_thresholds=None, criterion='squared_error', min_samples_leaf=1, min_weight_fraction_leaf=0.0, max_features=None, random_state=None, min_impurity_decrease=0.0)[source]#

Bases: PivotTreeStump, DecisionTreeStumpRegressor

Pivot stump for regression: a threshold on the distance from a pivot, an instance of the training set (distance <= t goes left).

At each node, the candidate pivots are selected among the instances of the node: the instance whose distance best separates high and low values of the target (descriptive pivot) and the one found by a regression tree on the distances (discriminative pivot). The split is the best threshold on the distance from one of the candidates. Distances are computed on the standardized numerical features; the distance matrix of the training set is computed once and cached in the tree. In the rules, P_<i> is the distance from the training instance i.

It is a Stump made of a PivotTransformer and a RegressionSplitter; it supports only tabular data.

Parameters:

  • distance_measure (str or callable, default='euclidean') – Distance between the instances, computed on the standardized numerical features: any metric of sklearn.metrics.pairwise_distances.

  • k (int, default=None) – Regression only: number of nearest and farthest instances used to measure how well a candidate pivot contrasts close and distant instances. None for the square root of the number of instances of the node (between 5 and n - 1).

  • reg_contrast_lambda (float, default=0.2) – Regression only: weight of the contrast with respect to the gain of the split when the descriptive pivot is selected.

  • reg_max_thresholds (int, default=None) – Regression only: maximum number of thresholds tested on the distances from each candidate pivot (quantiles). None for max(256, sqrt(n)).

  • criterion ({'squared_error', 'absolute_error', 'poisson'}, default='squared_error') – Impurity measure.

  • min_samples_leaf (int or float, default=1) – Minimum number of instances in each child (a fraction of the instances of the node if float). Applies to the numerical features.

  • min_weight_fraction_leaf (float, default=0.0) – Minimum fraction of the sample weights of the node in each child. Applies to the numerical features.

  • max_features (int, float, {'sqrt', 'log2'} or None, default=None) – Number of numerical features considered for the split, drawn at random; None for all.

  • random_state (int, RandomState instance or None, default=None) – Seed of the choice of the features (max_features) and of the ties between features with the same gain. With None, a tree gives the stump its own random_state.

  • min_impurity_decrease (float, default=0.0) – A numerical split is kept only if it decreases the weighted impurity by at least this value.

Variables:

  • transformer (PivotTransformer) – The fitted transformer.

  • splitter (RegressionSplitter) – The fitted splitter (feature, threshold, gain and impurity of the split).

  • data_type (str) – Data type the stump was fitted on.

  • feature_original (int) – Index (in the training set) of the pivot of the split.

  • threshold_original (float) – Threshold of the split.

  • X_split_instance (numpy.ndarray) – The pivot, as standardized numerical features.

See also

ProximityTreeStumpRegressor: which of two shapelets is closer to the time series, for regression.

class ProximityTreeStumpRegressor(n_shapelets=8, n_shapelets_for_selection=500, n_ts_for_selection_per_class=100, sliding_window=50, selection='mi_reg', distance='euclidean', mi_n_neighbors=100, random_state=42, n_jobs=1, criterion='squared_error', min_samples_leaf=1, min_weight_fraction_leaf=0.0, max_features=None, min_impurity_decrease=0.0)[source]#

Bases: ProximityTreeStump, ShapeletTreeStumpRegressor

Proximity stump for regression of time series: the time series closer to one shapelet than to another one go left (euclidean(TS, green_shp) <= euclidean(TS, red_shp)).

At each node, n_shapelets shapelets are selected as in ShapeletTreeStumpRegressor, and the split is the pair of shapelets whose comparison best splits the node. Unlike the shapelet stump, the rule has no threshold: it only says which shapelet the time series resembles more. In the Graphviz drawing, the first shapelet is green and the second one red.

It is a Stump made of a ProximityTransformer and a RegressionSplitter. The time series have shape (n_samples, n_signals, length) and are passed to the trees as X_ts.

Parameters:

  • min_impurity_decrease (float, default=0.0) – A numerical split is kept only if it decreases the weighted impurity by at least this value.
