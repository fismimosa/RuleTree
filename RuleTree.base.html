RuleTree.base.RuleTreeBase module#

Base classes for RuleTree estimators.

class RuleTreeBase[source]

Bases: BaseEstimator, ABC

Base class for RuleTree estimators.

RuleTree estimators may receive one input container for each supported data type: X for tabular data, X_ts for time series, X_img for images, and X_txt for text. The only assumption made by this base class is that the first dimension of every provided container is the number of samples. This is enough to validate that all provided inputs, and y when available, refer to the same set of instances.

Internally, the inputs are handled as a single dictionary {data_type: array} (see RuleTree.utils.define.DATA_INPUT_TYPES), built by _validate_inputs().

Notes

The class follows the scikit-learn estimator API by inheriting from sklearn.base.BaseEstimator. The base implementation only validates inputs; concrete estimators are expected to implement the actual fitting and prediction behavior.

See also

RuleTree.base.RuleTreeBaseStump module#

Abstract base class of the stumps: the single splits that make up the nodes of a RuleTree.

class RuleTreeBaseStump[source]

Bases: BaseEstimator, ABC

Abstract base class of the stumps, the splits of the nodes of a RuleTree.

A stump divides the instances of a node into two children: apply returns 1 for the instances that go to the left child and 2 for the ones that go to the right child.

Notes

Stumps receive the whole data set as a dictionary data = {data_type: array} (see RuleTree.utils.define.DATA_INPUT_TYPES) together with idx, the indices of the instances reaching the node. A fitted stump works on a single data type, chosen by the tree among supported_data_types and stored in data_type_. For convenience, data can also be a single array, interpreted as data of the stump’s data type.

The tree passed as context holds a cache that lives until the next fit (or clear_cache()), where stumps can store anything that can be shared among splits, e.g. embeddings computed on the whole data set. The stumps of the same class with the same hyperparameters share a cache, named by cache_namespace(). Everything needed by apply must be stored in the stump itself.

Subclasses that work on a 2D matrix can implement _transform (data of the stump’s data type -> matrix) and _apply_matrix (matrix -> 1/2 labels) and reuse apply() and update_statistics(). The stumps of the library are made of a transformer and a splitter (see RuleTree.stumps.Stump.Stump), which is the simplest way to write a new stump.

Variables:

  • supported_data_types (tuple of str) – Data types the stump can be fitted on.

  • task (str) – Kind of target, MODEL_TYPE_CLF (classification) or MODEL_TYPE_REG (regression).

  • data_type (str) – Data type the stump has been fitted on.

See also

RuleTree.stumps.Stump.Stump

a stump made of a transformer and a splitter, the simplest way to write a new stump (see Extending the library).

RuleTree.base.RuleTreeBaseSplitter module#

Abstract base class of the splitters: the component of a stump that finds the best split of a feature matrix (the matrix produced by the stump’s transformer, see RuleTreeBaseTransformer).

class RuleTreeBaseSplitter[source]

Bases: BaseEstimator, ABC

Abstract base class of the splitters, the component of a stump that finds the best split of a feature matrix: a threshold on a numerical feature (x <= threshold goes to the left child) or a value of a categorical feature (x == value goes to the left child).

A new splitter implements fit(), which sets the attributes below; apply(), get_state() and set_state() work for any split of this form. Splitters are scikit-learn estimators: their parameters are the arguments of __init__.

Variables:

  • task (str) – Kind of target: MODEL_TYPE_CLF (classification) or MODEL_TYPE_REG (regression). Class attribute.

  • feature (int) – Column of the matrix used by the split.

  • threshold (float or object) – Threshold (numerical split) or value (categorical split).

  • is_categorical (bool) – Whether the split is categorical.

  • gain (float) – Gain of the split: the stumps with the highest gain are chosen with stump_selection=’best’.

  • impurity (list of float or None) – Impurity of the node and of the two children, if computed.

See also

RuleTreeBaseGainSplitter

a simpler interface, where only the gain of a split is defined.

Examples

A splitter that splits the first numerical feature at its median (see Extending the library):

>>> import numpy as np
>>> from RuleTree.base.RuleTreeBaseSplitter import RuleTreeBaseSplitter
>>> from RuleTree.utils.define import MODEL_TYPE_REG
>>> class MedianSplitter(RuleTreeBaseSplitter):
...     task = MODEL_TYPE_REG
...
...     def fit(self, X, y, numerical, categorical, sample_weight=None, check_input=True):
...         self.feature_ = numerical[0]
...         self.threshold_ = float(np.median(X[:, self.feature_]))
...         self.is_categorical_, self.gain_, self.impurity_ = False, 0.0, None
...         return self

>>> MedianSplitter().fit(X, None, numerical=[0], categorical=[]).apply(X)

RuleTree.base.RuleTreeBaseGainSplitter module#

Base class of the splitters defined by a gain function: the simplest way to write a new splitter.

class RuleTreeBaseGainSplitter[source]

Bases: RuleTreeBaseSplitter, ABC

Base class of the splitters that test every candidate split and keep the one with the highest gain: a new splitter only defines the task (task) and the gain of a split (gain()).

The candidate splits are the thresholds halfway between consecutive distinct values of each numerical feature (x <= threshold goes left) and the values of each categorical feature (x == value goes left). Splits with fewer than min_samples_leaf instances on a side are skipped. The search is exhaustive and not optimized: gain is called once per candidate.

Variables:

min_samples_leaf (int) – Minimum number of instances on each side of a split. 1 unless the subclass sets it (e.g. as a parameter of __init__).

See also

RuleTreeBaseSplitter

the attributes set by fit.

Examples

>>> import numpy as np
>>> from RuleTree.base.RuleTreeBaseGainSplitter import RuleTreeBaseGainSplitter
>>> from RuleTree.utils.define import MODEL_TYPE_CLF
>>> class MisclassificationSplitter(RuleTreeBaseGainSplitter):
...     task = MODEL_TYPE_CLF
...
...     def gain(self, y, left, sample_weight=None):
...         # decrease of the number of errors when each side predicts its majority class
...         errors = lambda labels: len(labels) - np.unique(labels, return_counts=True)[1].max()
...         return errors(y) - errors(y[left]) - errors(y[~left])
>>> X = np.array([[1.0], [2.0], [3.0], [4.0]])
>>> splitter = MisclassificationSplitter().fit(X, np.array([0, 0, 1, 1]), numerical=[0], categorical=[])
>>> splitter.feature_, splitter.threshold_
(0, 2.5)

RuleTree.base.RuleTreeBaseTransformer module#

Abstract base class of the transformers: the component of a stump that turns the data of one type (tabular data, time series, images, …) into the feature matrix split by the stump’s splitter (see RuleTreeBaseSplitter).

class RuleTreeBaseTransformer[source]

Bases: BaseEstimator, ABC

Abstract base class of the transformers, the component of a stump that turns the data of one type into a feature matrix.

A new transformer implements transform() and, if it learns something from the data, fit() (and get_state()/set_state() to be saved with the tree).

A transformer is fitted on the whole data set of its type (X, all the instances) and on idx, the instances reaching the node, so that values computed on the whole data set can be shared among the splits through cache (a dictionary that lives as long as the tree’s cache).

After the splitter has chosen a feature, select() lets the transformer keep only what is needed to compute that feature (e.g. a single pivot); if the feature matrix changes, refit_after_select is True and the stump fits the splitter again on the new matrix.

Transformers are scikit-learn estimators: their parameters are the arguments of __init__.

Variables:

  • supported_data_types (tuple of str) – Data types the transformer can be fitted on. Class attribute.

  • refit_after_select (bool) – Whether select() changes the feature matrix. Class attribute.

  • numerical (list of int) – Indices of the numerical columns of the feature matrix. Set by fit().

  • categorical (list of int) – Indices of the categorical columns of the feature matrix. Set by fit().

See also

RuleTree.stumps.Stump.Stump

the stump that combines a transformer and a splitter.

RuleTreeBaseSplitter

the other component of a stump.

Examples

A transformer without fitted state defines only transform (see Extending the library):

>>> import numpy as np
>>> from RuleTree import RuleTreeClassifier
>>> from RuleTree.base.RuleTreeBaseTransformer import RuleTreeBaseTransformer
>>> from RuleTree.stumps.Stump import Stump
>>> from RuleTree.stumps.splitters import ClassificationSplitter
>>> from RuleTree.utils.define import DATA_TYPE_TS
>>> class MeanTransformer(RuleTreeBaseTransformer):
...     supported_data_types = (DATA_TYPE_TS,)
...
...     def transform(self, X):
...         return X.mean(axis=2)  # mean of each signal
...
...     def feature_id(self, feature):
...         return f"mean_{feature}"
>>> rng = np.random.default_rng(0)
>>> y = rng.integers(0, 2, size=50)
>>> X_ts = rng.normal(size=(50, 1, 20)) + 2 * y[:, None, None]
>>> stump = Stump(MeanTransformer(), ClassificationSplitter())
>>> model = RuleTreeClassifier(max_depth=1, base_stumps=stump).fit(X_ts=X_ts, y=y)
>>> model.get_rules()["textual_rule"].split()[0]
'mean_0'
